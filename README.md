# Red Apple Food Box

A simple website for Red Apple Food Box, a neighborhood store in Belton, Texas. It shows the store, what it sells, and how to find it.

This is a demo. It is not the official site of the store.

## What you will see

- A photo of the storefront
- A list of things the store sells
- A short story about the store
- A button that opens the store on Google Maps

## Notes

- The photos are AI-generated. They are not photos of the real store.
- The "Check inventory" button is not active yet.
- The contact form does not send messages.

## Run it

Open `index.html` in a browser. No install is necessary.
